**Goal:** A two-page personal site in Brazilian Portuguese where one procedural
tree carries everything — the home page is the tree from outside and is about
who Nicholas is; the blog is the same tree from inside, where every post is a
real branch you fly into, and each post's own words shape the world you read it in.

**Architecture:** One WebGL context and one tree survive every navigation; the
camera and the tree's state change instead of the page reloading. Branches
become individually addressable so a post can *be* a branch. Posts are Markdown
compiled at build time, and each post's world is generated from its own text —
paragraph count, length and tag — with an escape hatch for a hand-built scene
when a subject deserves one.

**Tech Stack:** Three.js (vanilla), Vite, TypeScript, Vitest, `marked` +
`gray-matter` (build-time only), Fontsource (self-hosted fonts).

## Global Constraints

- **Brazilian Portuguese first.** Every user-facing string is pt-BR;
  `lang="pt-BR"` on `<html>`.
- **Two pages only:** `/` and `/blog`, plus `/blog/:slug` for a post. No
  project grid, no card wall, no tag-filter UI.
- **Nicholas writes the posts.** These tasks build the publishing system. One
  example post ships and says to delete it.
- **The tree is never rebuilt.** Navigation changes the camera and which
  branches are lit. Regenerating geometry per route would throw away the whole
  illusion.
- Typography: **Instrument Serif** (display), **Instrument Sans** (body),
  **Geist Mono** (labels), all self-hosted via Fontsource. Instrument Serif has
  **one weight (400) plus italic** — hierarchy comes from size, italic and
  colour, never `font-weight`.
- Green palette, verified below; every text token clears WCAG AA (4.5:1) on all
  three surfaces.
- `prefers-reduced-motion: reduce` honoured by every animation, including the
  camera flights.
- Zero console errors and zero WebGL warnings on load is a release gate.
- Commit after each task.

## Concept

**Home is the tree from outside.** Full silhouette, the person, the invitation.
The trunk carries **rings** — one per learned skill, sized by how many years
he's had it. Hovering a skill in the DOM lights its ring in the world.

**Blog is the tree from inside.** The camera flies into the canopy. Every post
is a real, addressable branch with a floating label. There is no list — the
tree *is* the index.

**A post is its branch, alive.** Flying into a branch generates a world from the
post's own text: paragraph count sets the twig count, tag sets the palette, the
slug seeds the growth. As you scroll the post, the branch grows and lights
twig by twig, one per paragraph. The words literally shape and drive the thing
you're reading them in.

**Escape hatch.** When a subject deserves a hand-built scene, dropping
`content/worlds/<slug>.ts` next to the post replaces the generated world
entirely. Generated is the default so writing stays cheap; bespoke is available
so the site can stay surprising.

/**
 * Route table.
 *
 * Pure string work, kept apart from `Router` so the rules are testable without
 * a DOM or a history stack. `BASE` matters because the site is served from a
 * subdirectory on GitHub Pages and every internal link has to survive that.
 */

export type RouteName = 'home' | 'blog' | 'post' | 'notFound'

export interface RouteMatch {
  name: RouteName
  params: Record<string, string>
  path: string
}

export const BASE: string = import.meta.env.BASE_URL || '/'

export function stripBase(pathname: string, base: string): string {
  const trimmed = base.endsWith('/') ? base.slice(0, -1) : base
  let path = pathname
  if (trimmed && (path === trimmed || path.startsWith(`${trimmed}/`))) {
    path = path.slice(trimmed.length)
  }
  return path.startsWith('/') ? path : `/${path}`
}

export function matchRoute(path: string): RouteMatch {
  // Normalise the trailing slash so /blog and /blog/ are one route.
  const clean = path.length > 1 && path.endsWith('/') ? path.slice(0, -1) : path

  if (clean === '' || clean === '/') return { name: 'home', params: {}, path: clean }
  if (clean === '/blog') return { name: 'blog', params: {}, path: clean }

  const post = /^\/blog\/([^/]+)$/.exec(clean)
  if (post) return { name: 'post', params: { slug: decodeURIComponent(post[1]!) }, path: clean }

  return { name: 'notFound', params: {}, path: clean }
}

export function buildPath(name: RouteName, params: Record<string, string> = {}): string {
  switch (name) {
    case 'home': return '/'
    case 'blog': return '/blog'
    case 'post': return `/blog/${encodeURIComponent(params['slug'] ?? '')}`
    default: return '/404'
  }
}

/** Prefix a route path with the deploy base, for use in `href`. */
export function href(path: string): string {
  const base = BASE.endsWith('/') ? BASE.slice(0, -1) : BASE
  return `${base}${path}` || '/'
}
```

```ts
/**
 * History-API routing.
 *
 * Client-side so the WebGL context and the tree survive navigation. Rebuilding
 * the scene per page view would cost a second of shader compilation and throw
 * away the camera mid-gesture — and the whole concept depends on it being the
 * same tree throughout.
 */

import { BASE, matchRoute, stripBase, type RouteMatch } from './routes'

export class Router {
  private currentMatch: RouteMatch

  constructor(private handler: (match: RouteMatch) => void) {
    this.currentMatch = matchRoute(stripBase(location.pathname, BASE))
  }

  start(): void {
    addEventListener('popstate', this.onPopState)
    document.addEventListener('click', this.onClick)
    this.handler(this.currentMatch)
  }

  private onPopState = (): void => {
    this.currentMatch = matchRoute(stripBase(location.pathname, BASE))
    this.handler(this.currentMatch)
  }

  private onClick = (event: MouseEvent): void => {
    // Let the browser keep new tabs, downloads and external hosts.
    if (event.defaultPrevented || event.button !== 0) return
    if (event.metaKey || event.ctrlKey || event.shiftKey || event.altKey) return

    const anchor = (event.target as HTMLElement | null)?.closest('a')
    if (!anchor || (anchor.target && anchor.target !== '_self')) return
    if (anchor.hasAttribute('download')) return

    const url = new URL(anchor.href, location.href)
    if (url.origin !== location.origin) return

    event.preventDefault()
    this.navigate(stripBase(url.pathname, BASE))
  }

  navigate(path: string, replace = false): void {
    const base = BASE.endsWith('/') ? BASE.slice(0, -1) : BASE
    const full = `${base}${path}` || '/'
    if (full === location.pathname) return

    history[replace ? 'replaceState' : 'pushState']({}, '', full)
    this.currentMatch = matchRoute(path)
    scrollTo({ top: 0 })
    this.handler(this.currentMatch)
  }

  get current(): RouteMatch {
    return this.currentMatch
  }

  dispose(): void {
    removeEventListener('popstate', this.onPopState)
    document.removeEventListener('click', this.onClick)
  }
}
```

```ts
/**
 * Build-time Markdown pipeline.
 *
 * Reads `content/posts/*.md`, renders each to HTML, and exposes the result as
 * the virtual module `virtual:posts`. The browser receives finished HTML —
 * neither `marked` nor `gray-matter` is ever bundled.
 */

import { readdir, readFile } from 'node:fs/promises'
import { join } from 'node:path'
import matter from 'gray-matter'
import { marked } from 'marked'
import type { Plugin } from 'vite'

const VIRTUAL_ID = 'virtual:posts'
const RESOLVED_ID = '\0virtual:posts'
const POSTS_DIR = 'content/posts'
/** Reading speed for Portuguese prose, in words per minute. */
const WPM = 200

export interface Post {
  slug: string
  titulo: string
  data: string
  resumo: string
  tags: string[]
  minutos: number
  html: string
  paragrafos: number
  rascunho: boolean
}

export function slugFromFilename(filename: string): string {
  return filename.replace(/\.md$/, '').replace(/^\d{4}-\d{2}-\d{2}-/, '')
}

export function readingMinutes(text: string): number {
  const words = text.trim().split(/\s+/).filter(Boolean).length
  return Math.max(1, Math.round(words / WPM))
}

/**
 * Prose blocks only — headings, code fences and lists are not paragraphs.
 * This number becomes the twig count on the post's branch, so it has to track
 * how the text actually reads, not how many blank lines it contains.
 */
export function countParagraphs(markdown: string): number {
  const blocks = markdown
    .split(/\n\s*\n/)
    .map((b) => b.trim())
    .filter(Boolean)
    .filter((b) => !b.startsWith('#') && !b.startsWith('```') && !b.startsWith('---'))
  return Math.max(1, blocks.length)
}

export function parsePost(raw: string, filename: string): Post {
  const { data, content } = matter(raw)

  // Fail the build loudly. A post that silently renders with no title is worse
  // than a build that refuses to finish.
  if (!data['titulo']) throw new Error(`${filename}: frontmatter sem "titulo"`)
  if (!data['data']) throw new Error(`${filename}: frontmatter sem "data"`)

  const date =
    data['data'] instanceof Date ? data['data'].toISOString().slice(0, 10) : String(data['data'])

  return {
    slug: slugFromFilename(filename),
    titulo: String(data['titulo']),
    data: date,
    resumo: String(data['resumo'] ?? ''),
    tags: Array.isArray(data['tags']) ? data['tags'].map(String) : [],
    minutos: readingMinutes(content),
    html: marked.parse(content, { async: false }) as string,
    paragrafos: countParagraphs(content),
    rascunho: data['rascunho'] === true,
  }
}

export function postsPlugin(): Plugin {
  let isProduction = false
  let projectRoot = process.cwd()

  async function loadAll(): Promise<Post[]> {
    const dir = join(projectRoot, POSTS_DIR)
    let files: string[]
    try {
      files = (await readdir(dir)).filter((f) => f.endsWith('.md'))
    } catch {
      return []
    }
    const posts = await Promise.all(
      files.map(async (f) => parsePost(await readFile(join(dir, f), 'utf8'), f)),
    )
    return posts
      .filter((p) => !isProduction || !p.rascunho)
      .sort((a, b) => b.data.localeCompare(a.data))
  }

  return {
    name: 'posts',
    configResolved(config) {
      projectRoot = config.root
      isProduction = config.command === 'build'
    },
    resolveId: (id) => (id === VIRTUAL_ID ? RESOLVED_ID : null),
    async load(id) {
      if (id !== RESOLVED_ID) return null
      return `export const posts = ${JSON.stringify(await loadAll())};`
    },
    configureServer(server) {
      // Editing a post refreshes the browser without restarting Vite.
      server.watcher.add(join(projectRoot, POSTS_DIR))
      server.watcher.on('all', (_e, file) => {
        if (!file.endsWith('.md')) return
        const mod = server.moduleGraph.getModuleById(RESOLVED_ID)
        if (mod) server.moduleGraph.invalidateModule(mod)
        server.ws.send({ type: 'full-reload' })
      })
    },
  }
}
```

  // Sway scales with height above the roots, so the trunk holds and the canopy
